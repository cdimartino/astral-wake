# Local workshop command reference

Generated by `tools/hull_admin_reference.gd` from `scripts/hull_admin_registry.gd`.
See [the workshop guide](hull-workshop.md) for a complete walkthrough.

`[arguments]` are optional. Use Tab for the actual IDs in your current game or bank.
**Desk** works from any sandbox screen. **Expedition** requires an unfinished
run. **Combat** requires an active encounter. Wait for presentation to settle
before editing. Check **Recorded** to see which operations `scenario replay` repeats.

| Command | State | Recorded | Result |
| --- | --- | --- | --- |
| `help [query]` | desk | no | List commands or search their names, arguments and descriptions. |
| `inspect <section>` | desk | no | Inspect the screen, selection, resources, battle, piles, powerups, effects or scenario. |
| `run start <vessel> <seed>` | desk | yes | Start a seeded sandbox expedition; never replace the real expedition. |
| `region jump <region> [tier]` | expedition | yes | Place a region at this itinerary tier and generate a fresh chart. |
| `node jump <node>` | expedition | yes | Travel to a chart node, including unreachable nodes. |
| `room open <room> [event]` | expedition | yes | Open a shop, event, recovery room or ordinary encounter reward. |
| `encounter battle <regular>` | expedition | yes | Start a regular encounter with a catalog enemy. |
| `encounter elite <elite>` | expedition | yes | Start an elite encounter with its normal rewards. |
| `encounter boss <boss>` | expedition | yes | Reveal a guardian and its authored attendants. |
| `player set <resource> <number>` | expedition | yes | Set hull, salvage, ward, command points or a vessel-specific meter. |
| `organ strain <organ> <number>` | combat | yes | Set the strain on one organ (0 to current capacity). |
| `organ link <organ> <organ> <connection>` | combat | yes | Connect, cut or mend a conduit between two different organs. |
| `card add <card> [zone]` | expedition | yes | Add a new card UID to the deck; in combat also place it in a pile (default: draw). |
| `card remove <uid>` | expedition | yes | Remove a non-installed deck UID and its combat copy; keep at least five cards. |
| `card move <uid> <zone>` | combat | yes | Move an existing combat card UID. Use normal play to install cards. |
| `card draw <count>` | combat | yes | Draw up to ten cards with normal reshuffle and hand limits. |
| `powerup give <powerup>` | expedition | yes | Grant a catalog powerup. Start-of-battle bonuses apply next encounter. |
| `powerup remove <powerup>` | expedition | yes | Remove an owned powerup. |
| `foe spawn <enemy>` | combat | yes | Add a scaled enemy with the current turn’s intent (maximum eight). |
| `foe remove <foe>` | combat | yes | Remove a foe; removing the last foe resolves the encounter. |
| `damage <actor> <number>` | combat | yes | Apply damage to player or a zero-based foe index using normal defenses. |
| `heal <actor> <number>` | combat | yes | Repair a player or enemy up to maximum hull. |
| `status <actor> <status> <number>` | combat | yes | Set player mark/ward or foe disrupt/redirect. |
| `phase end` | combat | yes | End the turn using the ordinary player controller. |
| `resolve <outcome>` | expedition | yes | Resolve a battle win, voyage victory, or voyage defeat. |
| `act <action> [option]` | desk | yes | Activate a currently visible ordinary player action by option index. |
| `stage card <hand_uid>` | combat | yes | Select a hand UID using the normal card control. |
| `stage organ <organ>` | combat | yes | Route through an organ using the normal control and its contact sound. |
| `stage target <foe>` | combat | yes | Select a target by zero-based encounter index. |
| `preview` | combat | no | Preview the staged command through the ordinary controller. |
| `play <hand_uid> <route> <foe> [choices]` | combat | yes | Commit a card by UID through the game's normal play/presentation path; use comma-separated organ indices and optional choice UIDs. |
| `effect <effect>` | combat | yes | Preview a visual effect and its mapped sound without changing combat. |
| `scenario checkpoint` | desk | no | Capture the sandbox and begin a fresh command recording. |
| `scenario restore` | desk | no | Restore the checkpoint; keep the recording available for replay. |
| `scenario replay` | desk | no | Restore the checkpoint and run recorded commands against the current sound bank. |
| `scenario wait <seconds>` | desk | yes | Insert 1–30 seconds of listening time between replay steps. |
| `scenario stop` | desk | no | Stop replay before its next command. |
| `scenario list` | desk | no | List named scenario and shared comparison files. |
| `scenario save <name>` | desk | no | Save the checkpoint and recording to a named scenario file. |
| `scenario load <scenario>` | desk | no | Load a named scenario at its checkpoint, preserving the current bank. |
| `scenario export <name>` | desk | no | Write a shareable JSON comparison with scenario and current sound preset. |
| `scenario import <comparison>` | desk | no | Restore the scenario and sound preset from a shared comparison. |
| `audio <audio_args>` | desk | no | Use the Sound Desk command vocabulary; audio help lists mixer operations. |

## Sound Desk operations

Audio operations change the active mixer and are independent of scenario replay.

```text
audio packs
audio bank pack
audio groups
audio cues
audio patches
audio scores
audio voices
audio trace
audio variants cue
audio audition cue

audio group group mapping
audio mix scope parameter value
audio solo voice
audio mute voice
audio stinger stinger-or-switch [switch]
audio ab comparison
audio preset operation name
audio factory
audio undo
audio reload [manifest]
```
